# D2R Reimagined Trade Helper — расширение для Chrome

Удобный трейд на d2r-reimagined.com: массовое выставление, отметки «уже в трейде», цены на рынке,
мои объявления, предложения и чаты в одном окне со звуком и уведомлениями Windows.
Язык интерфейса по умолчанию — **английский**; переключатель **EN | RU** есть в заголовке обоих окон.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** (справа вверху).
3. **Загрузить распакованное** → выберите папку `d2r-bulk-trade` (где лежит `manifest.json`).
4. Откройте https://www.d2r-reimagined.com/trade и войдите на сайт.

После обновления: ↻ на карточке расширения в `chrome://extensions`, затем F5 на сайте.

## Массовое выставление (кнопка «☰ Bulk listing», слева внизу на страницах Trade)

- Все предметы с синхронизированных персонажей (надето, инвентарь, чарм-инвентарь, сундук, куб,
  наёмник) и из общего сундука — то же, что видит страница «List an item».
- Вид **▦ Инвентарь** — сетки как в игре, клик выбирает предмет, справа цена и заметка каждому.
  Вид **☰ Список** — одна таблица с сортировкой (сначала новые, по названию, качеству, ilvl, месту).
- Подсказка со свойствами при наведении; поиск по названию **и свойствам** (`life`, `skill`, `resist`).
- Зелёное **IN TRADE** — уже выставлен, жёлтое **PENDING** — принято предложение, ждёт сделки.
  **⇄ Синхронизировать с трейдом** заново загружает предметы и объявления и пишет, что не найдено
  (скорее всего, продано). Панель синхронизируется и сама при каждом открытии.
- Синее **NEW** — предмет появился с прошлого открытия панели (дату расширение запоминает само:
  в сохранении игры её нет).
- **Правый клик по предмету** (или кнопка 🔍) — **цены на рынке**: другие активные объявления
  с тем же предметом в той же лиге, игре и SC/HC, с ценами, продавцами и свойствами.
- Цена/заметка для всех или для каждого. Пустая цена = объявление без цены (покупатели предлагают сами).
- Перед отправкой — подтверждение, затем объявления уходят по одному с паузой, у каждого статус.

## Торговое окно (кнопка «💬 Trade», слева внизу на любой странице сайта)

- **📋 Мои объявления** — фильтр по статусу, поиск, смена цены прямо в таблице, «Снять»,
  «✓ Сделка прошла», «Вернуть в продажу», массовое снятие, 🔍 цены на рынке.
  **⇄ Синхронизировать с инвентарём** — где сейчас лежит каждый выставленный предмет.
- **💰 Предложения** — все офферы: принять (сайт резервирует предмет и отклоняет остальные), отклонить, чат.
- **💬 Чаты** — диалоги и переписка, Enter — отправить, готовые фразы на английском.
- **Звук и уведомления Windows** о новых сообщениях и предложениях, даже если Chrome свёрнут.
  Работает, пока открыта хоть одна вкладка сайта; звук — после первого клика по странице.

## Бережёт ресурсы

- На обычной странице сайта — три лёгких запроса после загрузки страницы (кто вы, ваши объявления,
  ваши чаты), дальше расширение слушает живое соединение сайта; запасная проверка — раз в 3 минуты,
  пока соединение работает (раз в 40 секунд, если нет), и только из одной вкладки.
- Предложения по объявлениям грузятся только при открытии вкладки «Offers»; данные предмета
  объявления скачиваются один раз и запоминаются в браузере.
- Панель выставления повторно использует инвентарь, загруженный за последние 3 минуты;
  свежие данные — кнопкой ⇄ Синхронизировать.
- Поиск перерисовывает сетку после паузы в наборе; звуковой движок работает только во время сигнала.

## Как это работает

Расширение работает внутри страницы сайта и использует ваш вход на сайте; данные никуда больше
не отправляются. Запросы — те же, что делает сам сайт (`https://api.d2r-reimagined.com`).
Живые события берутся из WebSocket-соединения сайта, плюс проверка раз в 40 секунд.
